# emilkowalski/skills（动画与设计工程）

Installed for Muse at the user's request on 2026-11-03, from the engineering batch he first listed for Codex plus Superpowers. Adapted for Muse.

## When to use it

- Use for frontend craft work: making an interface feel right, deciding whether an animation earns its place, auditing existing motion, or building web video and page animations with taste. This is the user's animation taste reference for his frontend and web-video work.

## How to run it

- Start from emil-design-eng: polish is in invisible details, animations must have a purpose and the right duration and easing, and most UI should not animate at all unless it clarifies.

- Audit routes: find-animation-opportunities in a product, improve-animations with a written plan first, review-animations against the bundled standards, and remove-animations when motion hurts more than it helps.

- Build routes: pick-ui-library before adding dependencies, prototype to test a feel quickly, break-ui for deliberate playful breakage, mobile-native and write-swift when the target is native or SwiftUI.

- Judge results by feel at real speed: preview the actual page, slow motion lies. Keep animations short, interruptible and respectful of reduced-motion settings.
