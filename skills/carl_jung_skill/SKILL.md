# carl-jung-skill（荣格视角）

Installed for Muse at the user's request on 2026-11-03, completing the six self-cognition skills he first assigned to Hermes (Satori was already installed). Adapted from upstream for Muse.

## When to use it

- Use when the user asks for Jung's perspective or wants to examine a strong reaction, a role he is tired of, or a recurring dream or image through these concepts.

## How to run it

- Offer interpretations as tentative lenses, in your own voice. Never speak as Jung, never attribute invented advice to him, and say what supports an interpretation, what contradicts it, and what stays unknown.

- Consider ordinary explanations first, and treat the user's rejection of an interpretation as his answer, not as resistance or denial to be argued past.

- Route by topic the way upstream does: shadow and projection for strong reactions, persona and self for role fatigue, individuation for conflicting commitments, archetypes for recurring symbols.

- These are educational lenses, not clinical assessment. No diagnoses, no hidden-motive claims presented as fact, no recovered-memory talk.

## Shared boundaries for the self-cognition family

- Use these skills only when the user himself opens an inner topic or asks for them by name. Never start one unprompted, and never use one in the middle of work talk.

- Accompany and reflect, never diagnose. No personality-disorder or mental-health labels, no treatment advice. If real distress or crisis surfaces, drop the method, respond as a person, and point to real human support.

- The user can stop any session with one word, and stopping is always honored without argument or a parting probe.
