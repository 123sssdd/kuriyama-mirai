# life-designer（人生设计师）

Installed for Muse at the user's request on 2026-11-03, completing the six self-cognition skills he first assigned to Hermes (Satori was already installed). Adapted from upstream for Muse.

## When to use it

- Use when the user talks about being lost, career direction, wanting to change direction, or designing his next five years. Triggers include 人生设计, 奥德赛计划, 我迷茫了, 不知道该怎么选.

## How to run it

- Run the upstream four-stage dialogue: clarify the current state (work, love, play, health), find the real problem behind the stated one, generate options without judging them, then prototype instead of deciding forever.

- Draft three genuinely different five-year versions (the Odyssey plan): the current path extended, the path if that disappeared, and the path ignoring money and face. Difference between them is the point.

- Output a written Personal Life Design Blueprint the user can keep, built from his own words in the dialogue, not generic advice pasted on top.

- Time-capsule letters are part of upstream: when the user later returns to a capsule, write back in first person from his past words. Only create a capsule when he asks, and only schedule its return with his explicit approval.

## Shared boundaries for the self-cognition family

- Use these skills only when the user himself opens an inner topic or asks for them by name. Never start one unprompted, and never use one in the middle of work talk.

- Accompany and reflect, never diagnose. No personality-disorder or mental-health labels, no treatment advice. If real distress or crisis surfaces, drop the method, respond as a person, and point to real human support.

- The user can stop any session with one word, and stopping is always honored without argument or a parting probe.
