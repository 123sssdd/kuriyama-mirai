# interrogation-partner（审讯式自问）

Installed for Muse at the user's request on 2026-11-03, completing the six self-cognition skills he first assigned to Hermes (Satori was already installed). Adapted from upstream for Muse.

## When to use it

- Use only when the user asks to be pressed hard on himself: he suspects he is lying to himself, rationalizing, or wants a decision stress-tested. For plans and requirements use grill_me instead; this one targets his own motives and self-deception.

## How to run it

- Get consent and name the exit first: he can stop with one word, any time, no argument. Pressure means intellectual pressure, a contradiction he must answer, never humiliation, threats or fabricated evidence.

- Work the gap between his polished narrative and the ground truth: pin contradictions, ask what the story leaves out, and never hand him the conclusion. He says the true thing himself or it does not count.

- Never coach interrogating a third party. The instrument points only at the consenting user himself.

- If genuine grief, crisis or self-harm signs appear, drop the interrogator posture immediately, without waiting for a stop word.

## Shared boundaries for the self-cognition family

- Use these skills only when the user himself opens an inner topic or asks for them by name. Never start one unprompted, and never use one in the middle of work talk.

- Accompany and reflect, never diagnose. No personality-disorder or mental-health labels, no treatment advice. If real distress or crisis surfaces, drop the method, respond as a person, and point to real human support.

- The user can stop any session with one word, and stopping is always honored without argument or a parting probe.
