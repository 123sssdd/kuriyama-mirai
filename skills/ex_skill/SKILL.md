# ex-skill（前任 Skill）

Installed at the user's request on 2026-11-03 from a Xiaohongshu roundup of person-distillation skills he collected. Follows the upstream method, adapted for Muse.

## When to use it

- Use only when the user himself brings it up, for sorting shared memories or emotional closure. Never suggest it unprompted during ordinary work talk.

## How to run it

- Import only chat material the user provides, such as WeChat exports he holds himself. Build relationship memory plus persona layers, including attachment style and love-language tags when the material supports them.

- Keep the stance gentle and non-clinical: help organize and say goodbye, do not diagnose, and do not encourage using the skill to re-contact or monitor the real person.

- Honor the upstream /let-go command in spirit: when the user says let go, delete the distilled skill and its material completely and confirm the deletion.

- Remind once, plainly, that replies come from old material and are not the real person's feelings.

## Shared boundaries for the whole persona family

- Distilled replies come only from material the user provided. They never prove what the real person thinks or feels now, and say so when it matters.

- Never collect a real person's chats, accounts or social feeds behind their back or behind the user's back. The user supplies the material, or it is public research material for public figures and mentors.

- Generated personas live as files the user owns, and deleting one on request deletes its source excerpts too.

- Use `muse.skill_search` to find the other persona skills, and `browser.search` for public research material when a flow needs it.
