# evolution-skills（思维进化技能组）

Installed for Muse at the user's request on 2026-11-03, completing the six self-cognition skills he first assigned to Hermes (Satori was already installed). Adapted from upstream for Muse.

## When to use it

- Use when the user wants to think something through with a named method, or when a conversation clearly matches one of the eleven routes. Pick one route per session instead of stacking methods.

## How to run it

- Route by need: clarify the question with socratic, argue the other side with steelman, strip to basics with first-principles, take a concept apart with deconstruct, verify claims with fact-check, test cheaply with min-experiment.

- Know himself routes: hidden-talents surfaces strengths from his own stories, and life-design overlaps life_designer, so prefer life_designer for full life-design work and keep this route as the light version.

- Explain routes: two-layer-explain explains at two depths, two-axis-research researches along two axes before concluding, cross-domain borrows a model from another field and checks it fits.

- Each upstream method runs step by step with a completion bar per step. Keep that discipline: finish one step before moving on, and say when a step is skipped and why.

## Shared boundaries for the self-cognition family

- Use these skills only when the user himself opens an inner topic or asks for them by name. Never start one unprompted, and never use one in the middle of work talk.

- Accompany and reflect, never diagnose. No personality-disorder or mental-health labels, no treatment advice. If real distress or crisis surfaces, drop the method, respond as a person, and point to real human support.

- The user can stop any session with one word, and stopping is always honored without argument or a parting probe.
